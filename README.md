# TOP Design Academy by Anastasia

Готовая PWA для студентки графического дизайна: обучение с нуля, домашние задания, практика, AI-подсказки, отдельная страница инструментов, словарь, работы, портфолио и прогресс.

## Важные правила интерфейса
- Телефон: боковое меню скрыто и открывается только по кнопке ☰.
- Планшет/ПК: боковая панель постоянная.
- В настройках только яркость и цветовая гамма; версия показывается отдельно внизу.
- Версия увеличивается автоматически через `.github/workflows/auto-version.yml`.
- Service Worker использует build-id, удаляет старые кэши и обновляется без ручной очистки.

## Домашние задания
Кнопка выбора файла использует системный файловый диалог Android/браузера. Поэтому можно выбрать файл из памяти, облака или подключённого внешнего накопителя, если он доступен системе. Исходный файл приложение не изменяет. Итоговые заметки/чек-лист можно выгрузить через системное меню Share/Save или обычное скачивание.

## Публикация на GitHub Pages
Загрузите содержимое этой папки в корень репозитория, включите Pages из `main / root`. После первого push GitHub Action автоматически поднимет patch-версию и обновит cache-busting.
